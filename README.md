# BatTestsRedactor

<img src="app.ico" alt="BatTestsRedactor" width="96" align="right">

Удобный редактор и запускатель bat-тестов для C/C++ проектов.
Позволяет писать тесты в простом текстовом формате, автоматически
прогонять их через ваш `.exe` и получать наглядный отчёт с указанием
пройденных и проваленных тестов.

## Возможности

### Редактор тестов
- Подсветка синтаксиса — заголовки, ожидания и комментарии разными цветами
- Сворачивание тестов по клику на номер слева
- Нумерация тестов в отдельной колонке
- Поиск и переход к тесту из панели результатов одним кликом

### Прогон тестов
- Автоматическая генерация `testN.txt` и `start.bat` из одного файла тестов
- Запуск всех тестов одной кнопкой (`F5`)
- Очистка `results.txt` перед каждым прогоном
- Автоматический поиск `.exe` в указанной папке

### Панель результатов
- Зелёные `✓` — пройденные тесты, красные `✗` — проваленные
- Детализация для провалов: блоки «Ожидалось» и «Получено»
- Сводка «Пройдено: N / M»
- Клик по тесту в панели переходит к нему в редакторе
- Ховер подсвечивает строку теста
